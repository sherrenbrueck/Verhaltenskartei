# Verhaltenskartei
Die Verhaltenskartei wurde für ein autistisches Kind entwickelt, das mit Hilfe einfacher Situationen sozial akzeptiertes Verhalten einüben soll. Zu jeder Situation muss entschieden werden, ob das Verhalten richtig oder falsch ist. Bei falschem Verhalten kann das richtige im Anschluss angezeigt werden.
